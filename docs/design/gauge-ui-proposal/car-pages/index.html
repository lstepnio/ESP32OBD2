What changes from today?

Separate Vehicle health and recent Alerts panels become a single list of useful issues. Raw fault summaries stop appearing in multiple places. Filtered codes disappear from ordinary history, notifications, counts and shared reports. Exact code management remains in Advanced.

We retain the universal connection pill, the unified Engine + optional Transmission vehicle model, existing alert storage and the existing configuration acknowledgement rules.

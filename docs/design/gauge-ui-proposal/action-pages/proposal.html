Interaction contract proposed for approval

  • Retain the configured upward entry gesture and arrow-only progress. Horizontal swipes browse; downward swipe or the top chevron returns. Browsing never executes a command.
  • Ordinary raised idle: Ready shows action, resolved timer and Hold to start. The Park/brake line is removed. The hold expresses action intent; it does not attest to or automatically verify Park or brake state. A 0.9-second hold is a prototype starting point requiring physical evaluation.
  • Release early, movement beyond the touch tolerance, leaving the control, navigation, focus loss or any change in required status cancels the hold. Revalidate identity, connection, guards, timer and protection at completion. Within actions, consume the action hold locally so it cannot also trigger pairing or a global long-press action. One uninterrupted hold admits at most one request; holding or releasing afterward cannot Stop or restart it.
  • Stop is a single tap. Keep it available during Starting and Active, in the same 152 × 48 logical-pixel region. Browsing to the other idle action retains Stop with the running-action context above it. No automatic Start or restart.
  • Missing coolant before Start: show No coolant and the one-minute cap, then the local hold with No coolant still visible. Remove the Park/brake line from this screen too. This is an exceptional second step, while retaining the approved one-minute warning before commitment. During a run, keep the shortened timer and No coolant. Recovery cannot extend the deadline.
  • Restoration: The red spinning ring covers internal Return and verification states, without claiming success. After verified normal idle, go directly to Ready. Remove the Normal idle screen entirely. A known high temperature keeps Start blocked until fresh acceptable coolant returns. Releasing the original press cannot trigger a new action.
  • Unknown: persist Check idle / Status unknown until actual reconciliation. Never dismiss automatically or replay an uncertain Start. Navigation must preserve access to the unresolved action.
  • ABS/TCS: retain a named Disable confirmation with Restart to restore because this is a different consequence and recovery path. Do not imply a normal Enable toggle. Public qualification and installed execution remain disabled.
  • Critical alerts preempt ordinary content and preserve the protective operation underneath. A CEL indicator and essential alert content must use reserved regions, never overlap the timer or Stop. The exact combined alert layout will reuse the shared alert contract during implementation.

Geometry and copy rules

  • 240 × 240 logical circle. All essential text and primary-control corners fit radius 112; respect per-board safe-area mapping for other displays.
  • Stable hierarchy: action name at 20 px, time at 44 px, primary control at 16 px. One optional support line at 14 px. No Park/brake copy. Keep No coolant or the running-action context where it changes the meaning. Do not shrink these to fit extra content. State text can replace the timer at 19–28 px.
  • Primary control is 152 × 48 pixels. The return chevron needs a distinct 44 × 44 hit region. Neither intersects the primary control or pager. Dots communicate position; they are not tiny interactive targets.
  • Do not use color alone for action or outcome. Green controls have explicit verbs. Starting uses a green spinning ring and play symbol; stopping uses a red spinning ring and stop symbol; reconnecting uses a yellow spinning ring and connection symbol. The rings replace status words, with symbols and state context so color is not the only cue. These indicate pending work, never percent complete. Stop animation when the state resolves, and surface Unknown instead of endlessly spinning after an uncertain command. Honor reduced-motion preference with a fixed arc. No animated background.
  • No raw PID, protocol, controller address, revision, repeated action labels or routine explanatory paragraphs on the gauge. Unknown, unavailable, high and zero remain distinct meanings.
  • Reuse shared components and state data; no new framebuffer or font allocation is implied by these concept renders. Use existing generated fonts where possible; confirm real glyph metrics before implementation. Reuse the existing LVGL arc/ring component and bounded animation timer for progress; no extra framebuffer is needed. The outer ring fits decorative radius 116 and stays outside primary-control corners.

App companion

Action pages become compact named rows. Tap to edit duration and the shared coolant limit; remove lives in the editor, reorder in one named overflow control. Pressure-based four-tire timing stays optional and must remain clearly an estimate, never measured tire pressure. Save uses the existing durable setup transaction and honest pending/applied state. The shared connection pill keeps transport details out of each row.

Approval and implementation boundary

Submitted review 3 is preserved, including comments on screens marked unreviewed. Every byte-identical approved screen with unchanged meaning retains its approval. The approved no-coolant entry artwork is unchanged but needs renewed review because the following confirmation no longer has Park/brake text. Other unreviewed screens remain unreviewed; the removed Normal idle screen stays in the archive. Removing Park/brake text is a presentation request, not evidence that Park/brake is verified or authorization to remove command guards. The current parked test still relies on owner-supervised conditions; implementation must keep that scope explicit in the action contract. Approval will select the interaction direction, then implementation must add hold cancellation/revalidation tests, fresh/missing/recovered/high coolant cases, direct Stop, unknown recovery and physical glove/touch checks. Gauge and App code, wire messages, vehicle commands and release flags are unchanged in this design-only branch. Review 4 also includes the post-thermal-stop blocked state so removing the success screen cannot accidentally imply that a hot engine is ready to restart.

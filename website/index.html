03 / THE ANDROID APP

Your setup.
One place.

Make it your dashboard: choose pages, set alerts, adjust the display and see your vehicle’s fault information in one place.

Alerts with context.

Set thresholds for any selectable reading, including transmission values. Threshold and check-engine events share severity, history, and context, with optional phone notifications.

One vehicle. Optional second adapter.

Most vehicles use one OBD-II adapter. Swaps like our 5.7L Hemi Wrangler can have separate engine and transmission ports. An optional second adapter brings both sources into one dashboard, with pages and alerts kept together.

Advanced fault filters.

Filter expected Engine or Transmission fault codes from everyday views while preserving the original diagnostic information. The gauge hides a CEL indication only when complete, fresh checks account for all reported codes.

More ways to make it yours.

A basic iPhone App and browser-over-USB setup are part of the plan. You should be able to configure the gauge’s core functions without relying on an Android phone.

iPhone: the essentials.

We’re working toward a basic iOS companion for core gauge setup and everyday use. It will have a smaller feature set than Android; phone-sourced police and road alerts may not be available.

Set up over USB.

Planned browser-based configuration will let you set up core gauge functions from a supported desktop browser over USB, without a smartphone App. Today’s USB recovery tool installs firmware; configuration is a separate feature still to come.

More with Android.

Android remains the fullest companion experience. Some phone integrations will remain Android-only. Police and road-alert integrations are still in development, with availability depending on the platform and provider.

IN DEVELOPMENT / OFF-ROAD ACTIONS

Air up. Winch.
Get back to the trail.

We’re developing vehicle-specific shortcuts that bring useful off-road controls to the gauge. Configure your actions in the Android App, then reach them from the display.

01 / ONBOARD AIR

Air up at raised idle.

A four-tire preset that estimates time from starting PSI, target PSI and a measured fill. Save your usual setup or override the time for one session. This is a timer estimate, not live tire pressure. Air up implementation and qualification ↗

02 / VEHICLE RECOVERY

A preset for winching.

Temporary raised idle during winching, with its own duration and a clear running state. Stop the session directly from the gauge when the recovery is complete.

03 / OFF-ROAD CONTROL

ABS + traction control.

An explicit action to disable ABS and traction/stability control on compatible setups.

Idle actions are being designed around time limits, coolant-temperature protection and a clear Stop action.

Not enabled in current public firmware. Compatibility and release checks are still in progress for our 5.7L Hemi-swapped Jeep Wrangler. Compressor-load and winching-load operation have not yet been tested.

What can it do today?+

Vehicle controls, phone-delivered road alerts, a basic iOS App and browser-over-USB configuration are in development or planning. Virtual gauges and Android Auto are exploratory. Follow the linked progress sections for each feature’s current scope.

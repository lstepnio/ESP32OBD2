Loading the recovery tool…

Recovery writes separate firmware regions and resets the OTA selector to the recovered image. It leaves eGauge NVS, pairing and configuration regions untouched. Other firmware layouts may store data differently: back up before replacing them. No erase-all option.

USB access stays in this browser. No gauge identity, credentials or serial logs are uploaded. Download hashes are checked before connecting; written regions are verified on the board.

BEFORE YOU CONNECT

A few essentials.

  1. Use desktop Chrome or Edge, and a USB data cable. Mobile browsers and Safari are not supported by this tool.
  2. Disconnect the board from vehicle wiring and other power sources. Connect it directly to your computer over USB.
  3. Close serial monitors and other flashing tools. Keep this tab open and the cable connected until verification finishes.
  4. Choose the board's USB serial port when your browser asks. The chip and flash size are checked before any write; those checks cannot identify the display hardware.
Board not found or connection failed?

Check the data cable and USB port. To enter download mode, hold BOOT, press and release RESET, then release BOOT. Choose the port and retry. After installation, press RESET if the board does not restart automatically.

If macOS or Windows still cannot see it, follow the official Waveshare USB and driver guidance ↗. A protected or encrypted board needs its original recovery process.

What if installation is interrupted?

Reconnect the same board, enter download mode if needed and retry. Completed regions are checked and skipped when they already match. A partial write can prevent booting until recovery finishes. The browser tries up to three USB speeds; it does not select a different device automatically.

When should I use this?

Use USB for initial setup or recovery when normal updates are unavailable. For an already paired, working gauge, use the Android App's signed Wi-Fi update flow.

Android 10 or newer. After firmware installation, check that the gauge boots and responds to swipes. Open eGauge on your phone and follow pairing to set up your pages and adapter.

Download Android APK GitHub releases ↗

Install on your Android phone
  1. Open this page on your Android phone and tap Download Android APK. If you downloaded it on a computer, copy the APK to the phone's Downloads folder.
  2. Open the completed download, or find it in Files → Downloads, and tap the .apk file.
  3. If Android asks, open Settings → Allow from this source for the browser or Files app you used. Return to the installer and tap Install. Menu names vary by phone.
  4. Open eGauge, allow its requested Bluetooth/Nearby devices permissions and follow the gauge pairing instructions.
  5. Turn Allow from this source off again after installation. Keep Play Protect enabled.
Already have eGauge, or installation failed?

Install over your existing App to retain saved setup. If Android reports an incompatible signature, or an older version will not install, do not uninstall to bypass it: your saved setup could be lost. Export a backup from eGauge first, and use an APK from the same signing identity. Development APKs are not guaranteed to update every earlier build.

Do not bypass a Play Protect block. Check that the download came from this page or the project's GitHub release, and contact the project if it is still blocked.

How many adapters? Most vehicles use one adapter in their standard OBD-II port. Some swaps, including our Hemi-swapped Jeep with separate ECM and TCM diagnostic ports, need two adapters, one per port. This is uncommon outside swapped vehicles.

Verified download hashes and build provenance ↗ apply to the hosted fallback downloads. GitHub assets use their own release notes and asset metadata. This is an unsupported development option; a successful install does not establish vehicle compatibility. Talk to us about your setup.

Need an older release?

  1. Open eGauge releases on GitHub ↗.
  2. Find the version you want and open its release. Development builds are marked Pre-release. Read the notes for compatibility and any withdrawal notice.
  3. Expand Assets below the release notes, then select the file to download.

Android App: choose a .apk file, when one is provided. Historical releases may not include an APK.

Firmware: choose a signed .egauge-dev-update package. Select its release above, download the package, then choose the file in the recovery tool. Do not unzip it. The tool verifies the firmware signature and compatible board, image format and toolchain before using the reviewed USB support regions. A release with a different layout or toolchain requires matching recovery support; do not flash an arbitrary .bin at guessed offsets.

GitHub's Source code (zip) and Source code (tar.gz) links contain developer source, not installable App or firmware packages. Check compatibility before installing an older build: it may not read settings saved by a newer version.

**Reading the status:** Aligned means the website claim or explicit future limit
matches the source, not that the feature is production-qualified. Missing on site
identifies an omission, not a requirement to expose every setting in marketing.
Stale on site means a delivered artifact, visual or scope statement lags source.
Overclaimed means a reachable claim lacks the promised implemented workflow.
Undocumented is reserved for implemented behavior without a canonical doc; none
was established in this pass. Candidate-only and planned features stay explicitly
unreleased until scope approval and corresponding qualification. Several omissions
will be better handled in compact setup/compatibility help than the homepage.

integrations. Rewriting those as current features would make accuracy worse.
